# Santosh Driver (Demo Android project)

A standalone educational driver-trip simulator. It is not Uber and does not connect to any real rideshare service.

## Included practice flow
1. Receive a simulated trip request
2. Accept or skip
3. Mark arrival
4. Verify the training PIN (`4826`)
5. Start/complete the trip
6. See demo earnings and completed-trip count

All locations, fares, distance, duration and PIN are fictional sample data. No account, passenger, payment, network, GPS or live navigation is used.

## Build an APK
1. Install Android Studio on a computer.
2. Open this `SantoshDriver` folder in Android Studio.
3. Allow Gradle sync and install Android SDK Platform 35 if prompted.
4. Choose **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
5. Android Studio will show the generated APK location (usually `app/build/outputs/apk/debug/app-debug.apk`).

This source project is provided; a compiled APK is not included.
